# Crear Ícono para News Scraper

## Opción 1: Buscar un Ícono de "Nano Banana"

1. Busca o diseña un ícono con temática de banana pequeña/tech
2. Formato: PNG, 512x512 píxeles (o más grande)
3. Guárdalo como: `icon.png` en el directorio raíz del proyecto

## Option 2: Usar Generadores Online

- **Favicon.io**: https://favicon.io/
- **Icon Generator**: https://www.iconsgenerator.com/
- **Canva**: Diseña tu propio ícono
- **DALL-E / Midjourney**: "minimalist banana icon for tech app, blue background"

## Opción 3: Usar Convertidor ICO

Si tienes una imagen PNG:

```bash
# Windows - Usar herramienta online
# https://convertio.co/es/png-ico/
```

## Requisitos del Ícono

- **Formato**: PNG o ICO
- **Tamaño**: Mínimo 256x256, recomendado 512x512
- **Nombre**: `icon.png` o `icon.ico`
- **Ubicación**: Raíz del proyecto (`news-scrapper/icon.png`)
- **Estilo**: Nano banana, colores tech (azul/amarillo), minimalista

## Una vez que tengas el ícono:

1. Guárdalo como `icon.png` en la raíz
2. El ejecutable lo usará automáticamente
3. Aparecerá en:
   - Bandeja del sistema
   - Barra de título de la ventana
   - Installer de Inno Setup
   - Acceso directo de Windows

---

**Tip**: Puedes usar un emoji de banana 🍌 como placeholder mientras consigues un diseño personalizado.
